## 🎯 Ce que fait Copilot BTP

| Module | Description |
|--------|-------------|
| 📁 **GED Chantier** | Gestion documentaire IA (devis, PPSPS, DOE, DC4, situations) |
| 🧾 **Facturation IA** | Extraction Gemini, autoliquidation TVA, situations de travaux, PPF 2026 |
| 🏗️ **Suivi Chantier** | Planning lots, réserves, PV réception, avancement % |
| 🧠 **Brain BTP** | Copilot IA : lecture CCTP, risques, devis auto, analyse clauses |
| 📊 **Analytics** | KPIs chantier, comptable, opérationnel |
| 👥 **Équipe** | Chefs de chantier, conducteurs travaux, artisans |

## 🚀 Quick Start

```bash
git clone https://github.com/LogixSolutions94/copilot-btp
cd copilot-btp
npm install
cp .env.example .env   # Remplir les clés Supabase + Gemini
npm run dev
```
